# 拼豆工具 微信小程序 V1.2 需求文档（简化版）

**文档版本**：V1.2（简化版）

**编制日期**：2026-06-10

**V1.2 简化说明**：

基于 V1.0/V1.1 开发实践，做出以下精简决策：

1. **移除「图片转像素图纸」模块**：实际开发验证准确度太低，无法达到可用水平，V1.2 彻底移除
2. **隐藏图库相关功能**：收藏图库、公开图库、图纸分类标签筛选等功能完成度不高，V1.2 隐藏不展示
3. **聚焦核心闭环**：仅保留「上传图片 → OCR识别图例 → 确认结果 → 统计消耗量」+「豆子单独出入库操作」两大核心流程
4. **像素编辑器**：继续保留入口，暂不开发

**产品定位**：微信原生小程序轻量化拼豆辅助工具。聚焦图纸图例 OCR 识别和拼豆库存管理两大核心能力，实现**上传图纸 → 识别图例 → 确认用量 → 管理库存**的完整闭环。基于开源 Tesseract OCR 引擎 + 小程序云原生能力实现零付费接口，面向拼豆手工爱好者，主打免费开源、轻量化、易上手。

**核心原则**：

1. 全站规避「AI、智能」等词汇，统一使用「图片文字识别」
2. 全功能无付费第三方接口，依托开源库、小程序云原生能力实现
3. 像素编辑器仅预留入口，暂不开发
4. 图纸识别仅解析**图纸自带图例文字**（色号+数量），不做像素色块识别推算
5. V1.2 精简聚焦，不开发不成熟功能，保证已上线功能的高质量闭环

# 一、项目整体概述

## 1.1 项目背景

针对拼豆手工爱好者日常痛点，打造免费无门槛的拼豆辅助工具。V1.2 聚焦两个核心场景：

1. **图纸图例识别**：上传现成拼豆成品图纸，OCR 识别图例中的色号和数量，快速获得用料清单
2. **拼豆库存管理**：手动/批量出入库，实时掌握库存状况

## 1.2 运行环境

- 终端：手机微信客户端（iOS/安卓全机型适配）
- 运行载体：微信原生小程序
- 部署方式：自有 Node 服务部署
- 配置要求：后端服务器需安装 Tesseract OCR 引擎（tesseract-ocr + tesseract-ocr-chi-sim 语言包）

## 1.3 技术架构

- **小程序前端**：微信原生 WXML + WXSS + JavaScript + 原生Canvas
- **后端服务**：Node.js + Express + node-tesseract-ocr
- **数据库**：MySQL
- **文字识别能力**：node-tesseract-ocr（基于开源 Tesseract OCR 引擎），服务端运行，支持中英文混合识别（chi_sim+eng）
- **图片处理**：sharp（图片裁剪、缩放、格式转换）
- **鉴权**：JWT Token（微信 OpenID 登录 + Token 签发）

## 1.4 版本范围说明

### V1.2 实现功能

- 微信授权登录
- 图纸图例 OCR 识别（上传图片 → 识别色号+数量 → 人工校验 → 确认结果）
- 豆仓管理（手动出入库、库存查看、库存预警）
- 用料清单查看与复制
- 库存统计（结合识别结果对比库存缺口）

### 移除/隐藏功能

1. ~~图片转像素图纸~~：准确度不达标，彻底移除
2. ~~图纸图库浏览~~：隐藏，不展示
3. ~~图纸收藏~~：隐藏，不展示
4. ~~图纸标签分类筛选~~：隐藏，不展示
5. ~~像素编辑器~~：保留入口，点击提示开发中

## 1.5 全局通用规则

- **文案规范**：禁止使用「AI、智能生成」，统一使用「图片文字识别」
- **免责声明**：全站页面底部固定展示：`本工具仅供个人手工创作参考，禁止商用`
- **图片限制**：上传图片格式仅限 JPG/PNG，单张图片大小 ≤ 5MB
- **频次限制**：图纸识别功能设置每日使用上限
- **用户权限**：必须微信授权登录后使用核心功能
- **尺寸规范**：画布尺寸仅 58×58、58×87、58×116、87×116（宽×高，单位：颗）

# 三、小程序页面详细功能需求

## 3.1 登录授权页

### 3.1.1 页面入口
小程序首次打开、登录态失效时自动跳转。

### 3.1.2 功能模块
- 微信一键授权登录，获取用户昵称、头像、OpenID
- 无游客模式
- 授权成功自动跳转首页；授权拒绝弹窗提示

### 3.1.3 页面样式
简约原生布局，适配移动端触控操作。

## 3.2 首页（统计概览）

### 3.2.1 页面入口
用户授权登录后默认首页，作为拼豆模块的统计仪表盘。

### 3.2.2 统计卡片区域
- 库存总量（豆子总颗数）
- 已录入颜色种类数
- 低库存数量
- 缺货数量
- 库存预警提示卡片（有低库存/缺货时展示，引导去豆仓处理）

### 3.2.3 页面底部
- 免责声明：`本工具仅供个人手工创作参考，禁止商用`

## 3.3 图纸图例 OCR 识别页（核心功能）

### 3.3.1 页面入口
首页点击「图纸识别」进入。

### 3.3.2 核心能力
上传现成拼豆成品图纸图片，通过 OCR 识别图纸自带图例中的色号和数量，生成标准化用料清单。**仅识别图例文字（色号+数量），不依赖中文名，不做像素色块推算**。

### 3.3.3 操作流程

1. **上传图纸**：支持相册上传（JPG/PNG ≤ 5MB）
2. **裁剪图例区域**：前端裁剪聚焦图例区域，去除无关背景，提升识别准确率
3. **OCR 识别**：上传裁剪后图片，后端 Tesseract 识别图例文字，解析色号和数量
4. **色号校准**：自动匹配 MARD 221 标准色卡，修正格式差异
5. **人工校验**：展示识别结果，支持手动修改错误的色号/数量、删除无效条目、补充缺失内容
6. **选择尺寸**：手动选择图纸尺寸（58×58、58×87、58×116、87×116）
7. **确认结果**：用户确认后保存到个人图纸库，生成最终用料清单

### 3.3.4 结果展示

- 用料清单：色块预览 + 色号 + 颜色名称 + 所需数量
- 总计用量汇总
- 快捷操作：
  - **复制用料清单**：一键复制为文本格式
  - **核对库存**：对比当前库存，高亮缺口项
  - **批量出库**：根据用料清单一键扣减库存

### 3.3.5 限制与提示
- 页面展示当日剩余识别次数
- 图片超限、格式错误、内容模糊等场景展示对应提示
- 图例不清晰时提示「图例模糊，请上传清晰图纸重试」

## 3.4 个人图纸列表页（图纸 Tab）

### 3.4.1 页面入口
拼豆模块 TabBar「图纸」Tab 进入。

### 3.4.2 筛选区域
- **尺寸筛选**：58×58、58×87、58×116、87×116，支持单选
- **拼接状态筛选**：已拼 / 未拼，支持单选

### 3.4.3 图纸列表
- 列表卡片展示：图纸缩略图、名称、**尺寸标签**（如"58×58"）、**拼接状态标签**（已拼/未拼）、色号数量摘要
- 支持勾选参与库存统计（开关）
- 点击进入图纸详情（用料清单、核对库存、批量出库、复制清单）
- 支持删除图纸
- 列表上拉分页懒加载

### 3.4.4 统计范围
- 已勾选图纸参与库存核对和用料缺口计算
- 统计范围设置快捷入口

## 3.5 豆仓库存页（豆仓 Tab）

### 3.5.1 页面入口
拼豆模块 TabBar「豆仓」Tab 进入。

### 3.5.2 顶部数据统计
实时展示：豆子总颗数、已录入颜色种类、低库存数量、缺货数量。

### 3.5.3 入库功能（手动入库）

- 支持单条入库、批量入库
- 选择色号、填写数量与备注
- 提交后库存更新，日志标记「手动入库」

### 3.5.4 出库功能

- 支持单条手动出库、批量清单出库
- 自动校验库存余量，出库数量大于库存时拦截并提示「库存不足」
- 所有出库操作需二次确认

### 3.5.5 库存预警设置

- 用户自定义低库存阈值、缺货阈值
- 保存后全局生效
- 库存列表自动更新状态标识（绿色正常、黄色低库存、红色缺货）

### 3.5.6 库存日志

- 记录全部出入库操作
- 展示：操作时间、色号、操作类型、数量、备注、入库来源
- 支持筛选、分页查询

## 3.6 个人中心页（我的 Tab）

### 3.6.1 页面入口
拼豆模块 TabBar「我的」Tab 进入。

### 3.6.2 基础信息
展示微信头像、昵称、登录状态。

### 3.6.3 功能入口列表
- **图纸识别**（新增入口）：快捷跳转 OCR 识别页
- **订单 OCR 入库**：跳转订单识别入库页
- **库存预警设置**：快捷跳转预警设置
- **库存日志**：快捷跳转库存日志
- **切换模块**：返回模块选择页（记账/拼豆）
- **退出登录**：清空登录态，跳转授权页

# 四、后端 & 数据库设计

## 4.1 后端技术架构

| 组件 | 技术 | 说明 |
|------|------|------|
| 后端框架 | Express.js | 轻量成熟 |
| 数据库 | MySQL | 稳定可靠 |
| OCR 引擎 | node-tesseract-ocr | 开源 Tesseract，支持中英文 |
| 图片处理 | sharp | 裁剪、缩放、格式转换 |
| 鉴权 | JWT Token | 微信 OpenID + Token |

## 4.2 API 设计

### OCR 识别接口
```
POST /api/bead/ocr/recognize
  入参: { image: multipart/form-data }
  出参: { success, items: [{ colorCode, colorName, quantity }], rawText }
```

### 库存管理接口
```
GET    /api/bead/warehouse          - 查询库存列表
POST   /api/bead/warehouse/in       - 手动入库
POST   /api/bead/warehouse/out      - 手动出库
POST   /api/bead/warehouse/batch-out - 批量出库
GET    /api/bead/warehouse/logs      - 库存日志
GET    /api/bead/warehouse/alert     - 预警设置
PUT    /api/bead/warehouse/alert     - 更新预警设置
```

## 4.3 核心数据表

### 拼豆色卡表 bead_colors
存储 MARD 221 标准色卡数据（色号、颜色名称、色值）。

### 用户库存表 bead_inventory
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | int(主键) | 主键 |
| user_id | int | 关联用户 |
| color_code | varchar | 色号 |
| quantity | int | 数量 |
| update_time | datetime | 更新时间 |

### 库存日志表 bead_inventory_log
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | int(主键) | 主键 |
| user_id | int | 关联用户 |
| color_code | varchar | 色号 |
| type | varchar | 操作类型：in/out |
| quantity | int | 数量 |
| source | varchar | 来源：manual/batch |
| remark | text | 备注 |
| create_time | datetime | 操作时间 |

### OCR 识别记录表 bead_ocr_records
| 字段名 | 类型 | 说明 |
|--------|------|------|
| id | int(主键) | 主键 |
| user_id | int | 关联用户 |
| image_url | varchar | 原图地址 |
| items | json | 识别结果 [{colorCode, quantity}] |
| status | tinyint | 状态：0待确认 1已确认 |
| create_time | datetime | 创建时间 |

# 五、非功能需求

## 5.1 性能需求
- 小程序冷启动 ≤ 3s，热启动 ≤ 1.5s
- OCR 识别响应 ≤ 5s
- 库存列表渲染无卡顿，分页懒加载

## 5.2 兼容性需求
全机型、全微信版本适配，触控交互符合微信官方规范。

## 5.3 安全需求
- 无第三方密钥
- 接口统一 Token 鉴权
- 上传图片内容校验

## 5.4 易用性需求
关键操作二次确认，异常场景文字提示清晰，功能流程极简。
