## Context

myBudget 记账小程序已整合拼豆助手模块，8 个 Change 全部开发完成。基于实际使用反馈，做出以下简化决策：

1. **图片转像素图纸准确度太低**，彻底移除该模块（代码保留，入口隐藏）
2. **公开图纸库/收藏/分类功能完成度不高**，前端入口隐藏，代码保留
3. **聚焦核心闭环**：OCR 识别图例 → 确认结果进入个人图纸 → 统计消耗量 → 豆子出入库

## Goals / Non-Goals

**Goals:**
- 拼豆模块 TabBar 保持 4 Tab 结构，但内容重新定义：首页（统计）、豆仓、图纸（个人）、我的
- 首页改为统计概览仪表盘，展示库存数据和预警
- 图纸 Tab 改为个人图纸列表（OCR 确认结果），支持勾选参与统计
- 识别记录合并进图纸 Tab，不再独立
- 移除图片转像素入口，隐藏公开图纸相关入口
- 后端 API、数据库、已完成的页面代码全部保留不动

**Non-Goals:**
- 不删除任何已完成的代码文件
- 不修改后端 API 或数据库表结构
- 不实现新的后端功能
- 不改动记账模块（零影响）

## Decisions

### D1: TabBar 保持 4 Tab，内容重新定义

**选择**：4 Tab — 首页（统计概览）+ 豆仓 + 图纸（个人图纸列表）+ 我的
**理由**：重要模块各自独立 Tab，比把所有入口挤在首页更清晰。图纸作为核心功能之一值得独立 Tab。
**变化**：原来图纸 Tab 展示公开图纸库，现在改为展示个人 OCR 识别确认后的图纸列表。

### D2: 首页改为统计概览

**选择**：首页不展示快捷入口和搜索，改为展示库存统计数据
**内容**：
- 顶部统计卡片：库存总量、已录入颜色种类、低库存数、缺货数
- 库存预警提示卡片（有低库存/缺货时展示，引导去豆仓处理）
- 底部免责声明
**理由**：快捷入口模式下首页价值低（重要功能都在独立 Tab），统计概览给用户一眼掌握库存状况。

### D3: 图纸 Tab = 个人图纸列表

**选择**：图纸 Tab 展示 OCR 确认后的个人图纸，不再展示公开图纸库
**功能**：
- 图纸列表卡片展示：缩略图 + 名称 + 尺寸标签（58×58等） + 拼接状态标签（已拼/未拼）+ 色号数量摘要
- 筛选栏：拼接状态筛选（已拼/未拼）+ 尺寸筛选（58×58、58×87、58×116、87×116）
- 勾选参与库存统计（开关）
- 点击进入图纸详情（用料清单、核对库存、批量出库、复制清单）
- 支持删除已识别图纸
**理由**：OCR 识别确认后的图纸就是用户的个人图纸库，不需要额外的识别记录页面。拼接状态和尺寸是用户管理图纸最常用的两个维度。

### D4: OCR 识别后选择图纸尺寸

**选择**：OCR 识别确认结果后，用户需手动选择图纸尺寸
**流程**：上传图纸 → 裁剪图例 → OCR 识别 → 人工校验 → **选择尺寸（58×58/58×87/58×116/87×116）** → 确认保存
**理由**：OCR 无法自动判断图纸尺寸，尺寸信息是后续筛选和统计的基础数据，必须在确认时录入。

### D4: 识别记录合并进图纸 Tab

**选择**：去掉个人中心的「识别记录」独立入口，识别结果确认后直接进入图纸列表
**理由**：识别记录和图纸列表本质是同一份数据，分开展示造成概念混乱。

### D5: 我的页面精简

**选择**：只保留必要功能入口
- 订单 OCR 入库
- 库存预警设置
- 库存日志
- 切换模块
- 退出登录
**隐藏**：收藏、识别记录、像素编辑器入口

## Risks / Trade-offs

- **[TabBar 改动]** → 4 Tab 的 tabList 配置需要修改 custom-tab-bar，需要确认图标资源 → 风险低，纯配置改动
- **[首页重构]** → 从快捷入口页改为统计页，需调用库存统计 API → 已有后端 API，前端展示层改动
- **[图纸 Tab 改造]** → 从公开图纸列表改为个人图纸列表 → 需调整数据源和 API 调用，但后端 API 已就绪

## Implementation Scope

### 需要修改的文件（前端仅）

1. **custom-tab-bar/index.js** — bead 组 tabList 调整图标/文案（首页改"统计"概念）
2. **bead/index/index.js** + **index.wxml** + **index.wxss** — 改为统计概览页
3. **bead/drawing/drawing.js** + **drawing.wxml** + **drawing.wxss** — 改为个人图纸列表（增加拼接状态/尺寸筛选 + 卡片标签展示）
4. **bead/ocr/ocr.js** + **ocr.wxml** — 识别确认流程增加尺寸选择步骤
5. **bead/profile/profile.js** + **profile.wxml** — 精简功能入口列表
6. **app.json** — tabBar.list 保持不变（代码保留）

### 不修改的文件

- 所有后端代码（routes、controllers、services、dao）
- bead/ocr/ocr.* — OCR 识别流程保持不变
- bead/warehouse/warehouse.* — 豆仓页面保持不变
- bead/drawing-detail/drawing-detail.* — 图纸详情页保持不变
- bead/order-ocr/order-ocr.* — 订单 OCR 页面保持不变
- bead/alert-settings/alert-settings.* — 预警设置页面保持不变
- bead/inventory-logs/inventory-logs.* — 库存日志页面保持不变
- bead/convert/convert.* — 代码保留，入口隐藏
- bead/favorites/favorites.* — 代码保留，入口隐藏
- bead/conversion-history/conversion-history.* — 代码保留，入口隐藏
