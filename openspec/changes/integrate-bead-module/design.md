## Context

现有 myBudget 是微信原生记账小程序，使用 Express + MySQL 后端，账号密码登录。现需将拼豆助手（图纸浏览、图片转像素、OCR识别、豆仓库存管理）作为新模块整合进同一小程序，共享登录、独立 tabBar、数据隔离。

Spike 验证结论：Tesseract OCR 整图识别准确率约 57%（7条识别出4条），需配合前端裁剪图例区域后识别 + 人工校验兜底。

**V1.2 简化**：基于开发反馈，图片转像素准确度太低，移除该模块；公开图纸库/收藏/分类功能隐藏入口，聚焦 OCR 识别 + 出入库核心闭环。

## Goals / Non-Goals

**Goals:**
- 拼豆模块 4 Tab：首页（统计概览）+ 豆仓 + 图纸（个人图纸列表）+ 我的
- 首页改为统计仪表盘，展示库存数据和预警
- 图纸 Tab 改为个人图纸列表（OCR 确认结果），支持尺寸/拼接状态筛选
- OCR 识别后手动选择图纸尺寸，确认后进入个人图纸库
- 保留订单 OCR 入库功能
- 移除图片转像素入口，隐藏公开图纸库/收藏/分类入口
- 后端 API、数据库、已完成的页面代码全部保留不动

**Non-Goals:**
- 不删除任何已完成的代码文件
- 不修改后端 API 或数据库表结构
- 不实现新的后端功能
- 不对现有记账模块做功能改动（零改动原则）

## Decisions

### D1: 自定义 TabBar 4 Tab，内容重新定义

**选择**：使用微信 `custom-tab-bar` 组件，拼豆模块 4 Tab — 首页（统计概览）+ 豆仓 + 图纸（个人图纸列表）+ 我的
**理由**：重要模块各自独立 Tab，比把所有入口挤在首页更清晰。图纸作为核心功能之一值得独立 Tab。
**变化**：原来图纸 Tab 展示公开图纸库，现在改为展示个人 OCR 识别确认后的图纸列表。

### D2: 首页改为统计概览

**选择**：首页不展示快捷入口和搜索，改为展示库存统计数据
**内容**：
- 顶部统计卡片：库存总量、已录入颜色种类、低库存数、缺货数
- 库存预警提示卡片（有低库存/缺货时展示，引导去豆仓处理）
- 底部免责声明
**理由**：快捷入口模式下首页价值低（重要功能都在独立 Tab），统计概览给用户一眼掌握库存状况。

### D3: 图纸 Tab = 个人图纸列表

**选择**：图纸 Tab 展示 OCR 确认后的个人图纸，不再展示公开图纸库
**功能**：
- 图纸列表卡片展示：缩略图 + 名称 + 尺寸标签（58×58等）+ 拼接状态标签（已拼/未拼）+ 色号数量摘要
- 筛选栏：拼接状态筛选（已拼/未拼）+ 尺寸筛选（58×58、58×87、58×116、87×116）
- 勾选参与库存统计（开关）
- 点击进入图纸详情（用料清单、核对库存、批量出库、复制清单）
- 支持删除已识别图纸

### D4: OCR 识别后选择图纸尺寸

**选择**：OCR 识别确认结果后，用户需手动选择图纸尺寸
**流程**：上传图纸 → 裁剪图例 → OCR 识别 → 人工校验 → 选择尺寸（58×58/58×87/58×116/87×116）→ 确认保存
**理由**：OCR 无法自动判断图纸尺寸，尺寸信息是后续筛选和统计的基础数据。

### D5: wx.reLaunch 切换模块

**选择**：模块间切换使用 `wx.reLaunch`，清空页面栈
**理由**：两个模块的 tabBar 页面路径不同，navigateTo 的页面栈会互相串扰。reLaunch 清空后重新进入，逻辑清晰。

### D6: Storage 持久化模块选择

**选择**：`wx.setStorageSync('currentModule', value)` 持久化
**理由**：用户选择模块后，下次打开小程序直接进入对应模块首页。
**退出机制**：两个模块的「我的」页面提供「切换模块」入口，reLaunch 回 portal 重新选择。

### D7: OCR 裁剪后识别方案

**选择**：前端裁剪图例区域 → 上传裁剪后图片 → 后端 OCR 识别 → 人工校验
**理由**：整图识别准确率不足（57%），裁剪后字更大更清晰，预期显著提升。人工校验兜底确保数据 100% 准确。

### D8: 后端路由前缀隔离

**选择**：`/api/auth/*`（共用）、`/api/budget/*`（记账）、`/api/bead/*`（拼豆）
**理由**：鉴权逻辑共用，业务数据完全隔离，清晰可维护。

### D9: 我的页面精简

**选择**：只保留必要功能入口
- 图纸识别（跳转 OCR 页）
- 订单 OCR 入库
- 库存预警设置
- 库存日志
- 切换模块
- 退出登录
**隐藏**：收藏、识别记录、像素编辑器入口

## Risks / Trade-offs

- **[自定义 tabBar 兼容性]** → 微信基础库 2.5.0+ 支持 custom-tab-bar，覆盖 99%+ 用户，风险低
- **[页面栈丢失]** → 模块切换用 reLaunch 清空栈，用户可能丢失未保存操作 → 在切换前弹窗确认
- **[OCR 准确率]** → 整图识别不可行，裁剪后仍需人工校验 → 需求文档已明确提供人工校验机制
- **[包体积]** → 新增所有拼豆页面在主包，需关注 2MB 限制 → 后续可升级为分包加载
- **[首页重构]** → 从快捷入口页改为统计页，需调用库存统计 API → 已有后端 API，前端展示层改动
- **[图纸 Tab 改造]** → 从公开图纸列表改为个人图纸列表 → 需调整数据源和 API 调用，但后端 API 已就绪
