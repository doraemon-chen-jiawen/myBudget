## Why

当前图纸图例 OCR 识别使用固定裁剪底部 30% 的方式，导致识别结果不准确。主要原因是：

1. **裁剪区域包含噪音**：固定 30% 会包含方格边框的数字标注，干扰 OCR 识别
2. **图例高度不固定**：不同图纸的图例区域约占 10-20%，固定比例无法适配

这导致用户需要反复调整或手动输入，影响使用体验。

## What Changes

- **新增智能检测功能**：利用色块间距特征自动识别图例区域（上方图案色块紧挨，图例色块有间距）
- **新增手动微调界面**：提供滑动条（范围 5%-40%，默认 15%）让用户精确调整裁剪区域
- **优化视觉反馈**：在原图上以虚线显示裁剪边界，上方区域半透明遮罩
- **新增防抖机制**：拖动滑动条时等待 300ms 后更新显示，避免性能问题
- **新增超时处理**：智能检测超过 500ms 未完成时使用默认值 15%，并提示用户
- **新增手动输入入口**：OCR 识别失败时提供"添加图例"按钮，支持手动输入

## Capabilities

### New Capabilities
- `legend-region-detection`: 图例区域智能检测与手动调整功能，包括自动检测算法、滑动条微调界面、视觉反馈展示、以及识别失败时的手动输入入口

### Modified Capabilities
- 无。此变更为新增功能，不修改现有规格要求

## Impact

**前端代码**：
- `frontend/miniprogram/pages/bead/ocr/ocr.js` - 修改裁剪逻辑，新增智能检测和滑动条交互
- `frontend/miniprogram/pages/bead/ocr/ocr.wxml` - 新增滑动条组件和裁剪边界显示
- `frontend/miniprogram/pages/bead/ocr/ocr.wxss` - 新增裁剪边界和遮罩样式

**后端代码**：
- 无需修改（OCR 识别接口保持不变，仅裁剪逻辑在前端处理）

**依赖**：
- 无新增外部依赖
- 使用小程序原生 Canvas API 进行图像分析

**数据存储**：
- 不记录裁剪区域设置（每次重新设置）
- 完整原图保存到图纸库（现有逻辑保持不变）
- OCR 识别结果与原图关联（现有逻辑保持不变）
